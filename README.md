**Приложение визуально демонстрирует работу двух алгоритмов синхронизации процессов в операционных системах: Строгое чередование (Strict Alternation) и Алгоритм Петерсона (Peterson's Algorithm) (2025)**  

MAUI интерфейс с динамическим обновлением 

В приложении два конкурентных процесса выполняются в отдельных потоках и соревнуются за вход в критическую секцию, каждый алгоритм реализован независимо для наглядного сравнения их поведения.  
Приложение наглядно показывает как в алгоритмах процессы ожидают входа, входят в критическую секцию, выполняют свою работу и выходят из нее.

- Многопоточное программирование
- Синхронизация потоков
- Работа с потоками (Thread)
- Визуализация конкурентных процессов
